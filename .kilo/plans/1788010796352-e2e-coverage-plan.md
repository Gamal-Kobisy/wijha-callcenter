# E2E Test Coverage Plan

## Goal
Cover every endpoint and business flow defined in `api.yaml` with E2E tests, plus critical end-to-end user journeys.

## Current State
- 9 E2E test files
- ~114 E2E tests
- Coverage gaps in pagination, filters, error paths, call status transitions, session edge cases, and full CRUD flows

## Gaps Identified

### 1. Owners (Client) Module
- [ ] `GET /owners?agent_id=` filter
- [ ] `GET /owners?page=&limit=` pagination edge cases (limit > 100, page 0, negative)
- [ ] `GET /owners` with no owners returns empty array
- [ ] `PATCH /owners/:id` with `next_dial_at` (snooze)
- [ ] `PATCH /owners/:id` with `agent_id=null` (unassign)
- [ ] `DELETE /owners/:id` cascade deletes `numbers`, `client_info`, `client_project`
- [ ] `POST /owners/:id/projects` with non-existent project → 404
- [ ] `POST /owners/bulk` with empty array → 400
- [ ] Duplicate phone merge preserves longer name on update path
- [ ] `GET /owners/statuses` with no data returns empty array

### 2. Calls Module
- [ ] `GET /calls?agent_id=` filter
- [ ] `GET /calls` with no calls returns empty `data`

- [ ] `POST /calls` without `project_id` skips project linking
- [ ] `POST /calls` with `duration=0` is valid
- [ ] `GET /calls/next?type=OWNER` filter
- [ ] `GET /calls/next?type=LEAD` filter
- [ ] `GET /calls/next` without `project_id` returns any type

- [ ] `GET /calls/statuses?from` only (no `to`)

### 7. Security

### 8. End-to-End Flows

- [ ] Agent self-service: login, view own calls, submit call, view own stats

## Execution Order
1. Fix gaps in existing test files (owners, calls, projects, users, sessions)
2. Add new test cases in existing files (do not create new files unless module is new)
3. Add E2E flow test in `api.e2e-spec.ts`
4. Run full E2E suite: `npm run test:e2e`
5. Run full unit suite: `npm test`

## Risks
- E2E tests require Docker DB running; CI must ensure `docker compose up -d db` before tests
- Some tests depend on specific IDs (e.g., `projectId=1` for Default Project); seed must be deterministic
- Session overlap merge logic is time-sensitive; use fixed timestamps

## Validation
- All 114 existing tests continue to pass
- New tests added: ~60-80 additional E2E tests
- Total E2E coverage: ~170-190 tests
